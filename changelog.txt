VERSION 2.0.2 - CLEAN INSTALL & STRUCTURE RESTORATION
1. Restored standard Mojang / Python game runtime directory structure: Java is placed strictly into runtime/java-runtime-delta/windows-x64/java-runtime-delta with .version verification (no orphan java-21 folders).
2. Resolved clean NeoForge installation failures:
   - Installer is executed in an isolated temporary directory via safe ArgumentList to prevent Win32 path quoting and Cyrillic encoding corruption.
   - Synchronized default NeoForge loader version (21.1.265) with server pack.toml.
   - Guaranteed automatic resolution and verification of all NeoForge client libraries via CmlLib manifest loader post-installation.
   - Added robust trailing path normalization for custom and default Minecraft directories.
3. Added diagnostic exit logging and localization for installer failure events.
4. Fixed CustomSkinLoader crash on Minecraft 1.21.1 / NeoForge: automatically inject '-Dcustomskinloader.ignorePatchFailure=true' JVM flag to prevent Transformation rule IllegalStateException on SkinManager.
