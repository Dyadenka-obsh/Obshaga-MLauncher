# Aperture Science Minecraft Launcher

Кастомный лаунчер для Minecraft 1.21.1 + NeoForge в стиле Portal 2. 
Разработан для проекта **OBSHAGA**.

## 🛠 Технологии
- **Python 3.13+**
- **Tkinter** (GUI)
- **Pillow** (эффекты ЭЛТ и обработка логотипов)
- **minecraft-launcher-lib** (установка Java 21, NeoForge и запуск игры)
- **packwiz-installer-bootstrap** (синхронизация сборки модов)
